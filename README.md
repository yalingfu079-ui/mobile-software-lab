# 移动软件课程实验

本仓库用于保存移动软件课程的 Android Studio 实验代码、实验截图、任务 PDF 和实验说明。

## 目录

- `experiments/`：按实验次数保存 Android Studio 工程
- `screenshots/`：运行结果和实验过程截图
- `docs/`：实验任务 PDF、报告和补充材料

## 提交规范

每次实验使用独立提交，提交信息建议使用：

```text
实验 N：实验名称
```

每次实验完成后同步保存：

1. 可运行的 Android Studio 工程代码
2. 运行结果截图
3. 实验说明或 README
4. 题目 PDF（如课程要求）

## 开发环境

- Android Studio 2026.1.4
- Android SDK Platform 35 / 37
- Android Build Tools 35.0.0 / 36.0.0
- GitHub：`yalingfu079-ui`
